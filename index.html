Privacy

📷 Camera is used only for waste identification and is not stored by default.

🎙️ Microphone is used only for voice interaction.

🕵️ Queries and feedback use anonymous identifiers — no personal information is required.

🧼 A privacy guard strips phone numbers and email addresses from input.

🔑 API keys are never exposed to the browser.

📊 Analytics are aggregated and anonymous.

Responsible AI

✅ Grounded answers — responses come from retrieved local rules, not guesses.

❓ Uncertainty handling — WasteWise can say "Not sure" instead of hallucinating.

🔎 Transparency — every answer shows the matched rule and source.

👥 Human verification — local rules remain authoritative and admin-verifiable.

♿ Accessibility — captions, voice, text fallback and high-contrast bins.

Help

📷 How to scan
Open the camera, show your waste in the frame, and tap the scan button.

🎙️ How voice works
Tap the microphone and speak naturally — captions show everything.

🌐 Change language
Use the 🌐 button — the whole app switches language.

🤷 If AI is unsure
WasteWise never guesses — it will ask a question or suggest a query.

❓ Submit a query
Open Query Centre to report wrong answers or local-rule mismatches.

📊 How feedback is used
Anonymous feedback helps institutions improve bins, signs and rules.

Demo Mode & Prototype Info

🧪 Demo Mode is ON. Mock services are used for Vision, RAG, Granite and Analytics.

👁 Vision — mock detection (demo item picker)

🎤 Speech — Web Speech API where available, simulated otherwise

🔎 RAG — local mock semantic retrieval over ~50 item types & 8 internal streams

🧠 Granite — MockGraniteService returns structured grounded responses

📊 Analytics — demo dataset + local interactions

🔌 Real services — VisionService, SpeechToTextService, TextToSpeechService, RAGService, GraniteService, ConversationService, FeedbackService, QueryService, AnalyticsService interfaces ready for production endpoints.

📍 QR deployment — open ?location=cafeteria, ?location=hostel to simulate scanning the QR code beside bins.

🗺️ 3-bin model — 🟢 Wet · 🔵 Dry · 🔴 Special is a configurable deployment model, not a universal legal standard.
